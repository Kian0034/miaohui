使用说明 v1.0
==================

【秒回 MiaoHui】纯本地搜索引擎。
- 支持图片/截图/视频帧/文件 0.3 秒召回
- 视频支持跳秒（视频帧会显示时间戳）
- 全局热键：
    macOS: ⌥ + Space
    Windows: Ctrl + Alt + Space
- 支持中文 OCR、视频 ASR 双索引

========================================================

macOS 版（MiaoHui-macOS-v1.0）
========================================================
1) 双击解压缩 zip
2) 把 MiaoHui.app 拖到「应用程序」文件夹
3) 首次启动：右键 → 打开（绕过 Gatekeeper）
4) 菜单栏出现「秒」字图标，⌥ Space 呼出搜索框
5) 首次启动后台会自动下载模型（~500MB，国内镜像）
6) 授权：
   - 首次弹出“需要访问桌面/文稿/下载”，点「好」
   - 如需全局热键：系统设置 → 隐私与安全性 → 辅助功能 → 勾选 MiaoHui

Windows 版（MiaoHui-Windows-v1.0）
========================================================
1) 解压缩 zip 到任意目录
2) 双击「启动秒回.bat」或直接运行 MiaoHui/MiaoHui.exe
3) 系统托盘出现「秒」字图标，Ctrl+Alt+Space 呼出搜索框
4) 首次启动后台自动下载模型（~500MB，国内镜像）

========================================================
常见问题
========================================================
Q: 没搜到想要的？
A: 托盘/菜单栏 → 看索引状态。首次全量索引几十万文件需要几分钟。

Q: 视频打开不跳秒？
A: Windows：推荐安装 mpv 或 PotPlayer；macOS 自带 QuickTime 无法精确定位，建议安装 mpv（brew install mpv）。

Q: 隐私？
A: 全程离线。缩略图 AES-256-GCM 加密，密钥存系统密钥链（macOS Keychain / Windows DPAPI）。敏感目录/文件默认排除，审计日志可查。
